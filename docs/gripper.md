# Nova5とGripper接続に関する注意点

この文書では、アームとグリッパーの接続手順と注意点について説明します。

使用したグリッパーは、**DH-Robotics社製のAG-160-95**です。
詳細は[こちら](https://jp.dh-robotics.com/product/ag)を参照してください。

## 準備
以下のものを用意してください。
- Gripper本体
- Gripper用ケーブル（付属）
- Nova5用の変換ケーブル（付属）
- フランジナット（付属）
- DobotStudio Proのインストール済みPC (Windows)

DobotStudio ProからNova5を操作できる状態にしておきます。


## グリッパーの取り付け
取り付ける際は、Nova5のエンドエフェクタが鉛直上向になるようにすると作業が行いやすいです。

1. フランジをNova5のエンドエフェクタに取り付けます。ネジを締める際は、4つのネジを対角線上に交互に締めることで、フランジが傾かないように注意してください。
2. フランジナットを使って、グリッパーをフランジに固定します。左右のネジを交互に締めることで、グリッパーが傾かないように注意してください。

## ケーブルの接続
まずはケーブルが正しく導通しているかをテスターなどで確認してください。
グリッパーのコネクターとNova5のTool I/Oポートはどちらも8ピンのコネクターです。
最低限以下の4つの信号線が接続されていることを確認してください。
画像はメス側のコネクターになっているため、左右が逆になっています。

- 中央ピン(8): GND
- キー溝の左側(2): RS485 B
- キー溝の右側(1): RS485 A
- キー溝の対角側(5): +24V
[グリッパーのピン配置](./img/dobot_pin_layout.png)

確認が取れたら、Nova5の電源をOFFにした状態で、グリッパーのケーブルを接続します。
キー溝の向きに注意してください。

## DobotStudio Proでの動作確認

1. Nova5の電源をONにし、PCと接続します。
2. DobotStudio Proを起動し、Nova5に接続します。
3. Nova5がTCPモードになっていた場合は、オンラインモードに切り替えてください。
4. DobotStudio Proで「設定」->「負荷設定」を開き、荷重を1kgに設定します。
5. 続いて、指示に従い「ワンクリック荷重補正」を実行し、自動で荷重と重心の校正を行います。
6. 荷重補正が完了後に動作確認を行います。
    1. DobotStudio Proの「Dobot+」Tabを開いて、DH_gripperといった名前のpluginを選択しinstallしてください
    2. install後、pluginを起動し、GUIからグリッパーの開閉操作ができることを確認してください。
7. 最後に操作モードをTCPモードに戻し、DobotStudio Proを終了します。

最初に電源をつけた際は、初期化に時間がかかる場合があります。青のLEDが点滅している間は、グリッパーの操作を行わないでください。
ここまでで、グリッパーの取り付けと接続が完了し、DobotStudio Proでの動作確認ができる状態になります。

## TCP/IP経由での操作

AG-160-95はTCP/IPで直接通信するのではなく、Nova5のDashboard APIからNova5のTool RS485ポート上にあるグリッパーへModbus RTUでアクセスします。Nova5のTCP/IP接続と既存のRS485配線を使う構成です。

制御経路は次のとおりです。

```text
Pythonクライアント --TCP/IP--> Nova5 Dashboard API --Tool RS485/Modbus RTU--> AG-160-95
```

#### 通信確認の手順

最初はDobotStudio ProのDH gripper pluginによる操作を停止し、読み取りだけで通信を確認します。Dashboard APIコマンドはNova5のDashboardポート（通常 `29999`）へ1行ずつ送り、応答を確認します。

1. `SetTool485(115200)` でTool RS485の通信速度を設定します。ファームウェアによってコマンドの対応状況が異なるため、実機のAPI一覧で利用可能か確認してください。
2. `ModbusCreate(127.0.0.1,60000,1,1)` でTool RS485上のModbus RTUスレーブ（AGのIDは既定値1）への接続を作成します。応答に含まれる接続IDを後続コマンドに使います。
3. `GetHoldRegs(id,512,1)` でAGの初期化状態フィードバック `0x0200` を1レジスタ読み取ります。値 `1` は初期化済み、`0` は未初期化です。
4. 通信確認後は `ModbusClose(id)` で接続を閉じます。

NovaのDashboard APIには `ModbusCreate`、`GetHoldRegs`、`SetHoldRegs`、`ModbusClose` が用意されています。コマンドの引数と応答形式は、使用中のNovaファームウェアに対応したAPIマニュアルでも確認してください。

#### testスクリプトの使い方

リポジトリのルートディレクトリから実行します。Nova5のIPアドレスが異なる場合は `--host` で指定してください。

```bash
# 読み取りのみ：初期化状態、把持状態、現在位置
uv run python test/check_ag160_gripper.py status

# グリッパーを初期化（動作するため明示確認が必要）
uv run python test/check_ag160_gripper.py initialize --confirm-motion

# 指定位置へ動かす（15〜800、動作するため明示確認が必要）
uv run python test/check_ag160_gripper.py move 400 --confirm-motion
```

`status`は読み取り専用です。`initialize`と`move`はグリッパーを動かすので、周囲に人や物がないことを確認してから実行してください。スクリプトは動作範囲を実測・確認した `15`〜`800` に制限しています。

位置と開口幅の実測値（開口幅には約1 mmの計測誤差があります）：

| 位置指令値 | 実測開口幅 |
| ---: | ---: |
| 800 | 78 mm |
| 400 | 42 mm |
| 200 | 22 mm |
| 100 | 11 mm |
| 20 | 4 mm |

この測定結果をもとに、動作指令は `15`〜`800` の範囲に制限します。中間値から開口幅を見積もる場合は、この実測点の間を近似して使い、精密な位置決めが必要な作業では対象物ごとに再確認してください。

### AGシリーズの主なレジスタ

| アドレス | 用途 | 値 |
| --- | --- | --- |
| `0x0100` (256) | 初期化 | `1`：原点復帰、`165`：再校正 |
| `0x0101` (257) | 把持力 | 20～100（%） |
| `0x0103` (259) | 目標位置 | AG仕様は0～1000。確認用スクリプトでは15～800に制限 |
| `0x0200` (512) | 初期化状態 | 読み取り専用。`0`：未初期化、`1`：初期化成功 |
| `0x0201` (513) | 把持状態 | 読み取り専用。`0`：移動中、`1`：目標到達、`2`：把持、`3`：対象物落下 |
| `0x0202` (514) | 現在位置 | 読み取り専用。現在位置 |

### パラメータの意味

#### 把持力（`0x0101`）

把持力は、グリッパーが指令位置へ移動して対象物をつかむ、または押し広げるときに使う力の設定です。値の範囲は `20`〜`100` で、百分率として指定します。たとえば `30` は設定範囲の30%を意味します。ニュートン（N）単位の実力ではなく、AG-160-95で何Nになるかをこの値だけから換算することはできません。対象物や指先、把持方向によって実際の力や滑りやすさが変わるため、把持力は低い値から確認してください。

DH Roboticsのマニュアルでは、位置移動中に設定した力で対象物を把持または押し広げると説明されています。したがって、これは「位置指令」と別の力設定であり、グリッパーを何mm動かすかを指定する値ではありません。

#### 目標位置（`0x0103`）

目標位置はAG仕様上 `0`〜`1000` の千分比（0〜1000‰）で指定し、`0x0202`から現在位置を読み取ります。これは開口幅をmmで直接指定する値ではありません。確認用スクリプトでは、実機で確認した動作範囲に合わせて `15`〜`800` に制限しています。

**手元のAG-160-95では、目標位置 `0` が閉じ側、`1000` が開き側です。** 

初期化方向 `0x0301` は位置目標とは別の設定です。`0`が「開く」（初期化時に最大開位置を基準にする、既定値）、`1`が「閉じる」（初期化時に最小閉位置を基準にする）です。

実測では位置指令値が大きいほど開口幅が広くなりました。測定した開口幅の誤差は約1 mmです。

出典：[DH Robotics AGシリーズ操作説明書（Modbus版）](https://www.dh-robotics.com/wp-content/uploads/2022/12/AG%E7%B3%BB%E5%88%97-%E6%93%8D%E4%BD%9C%E8%AF%B4%E6%98%8E%E4%B9%A6MODBUS-%E7%89%88V2.6-%E5%A4%A7%E5%AF%B0%E6%9C%BA%E5%99%A8%E4%BA%BA.pdf)（2.3.3.2「力值」、2.3.3.3「位置」、2.3.3.8「初始化方向」）。

位置・力・初期化レジスタへの書き込みは、初期化状態と動作方向を確認した後に行います。初回は対象物を挟まない状態で、低い把持力と小さい位置変化から試してください。`SetHoldRegs`の引数形式はNovaのAPI仕様に従います。

## 注意点と未検証事項

- **未確認**：指令値と`0x0202`実位置レジスタの数値関係、および対象物を把持する際の適切な把持力。
- DH gripper pluginとPythonクライアントを同時に使うと、同じRS485機器への通信が競合する可能性があります。Pythonで確認する間はpluginを停止してください。
- 実機では `SetHoldRegs` / `GetHoldRegs` が `-1` を返すことが断続的にありました。直後の同じコマンド再実行で成功した例がありますが、原因は未特定です。エラー時は成功扱いにせず、状態を読み直してから必要な指令を再実行してください。
